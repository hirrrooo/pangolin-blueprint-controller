# Security policy

## Supported versions

Security fixes are provided for the latest released minor version. Pre-release builds and older minor versions may require upgrading before a fix is available.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for suspected vulnerabilities.

Include:

- Affected version or commit
- Reproduction steps
- Expected and observed behavior
- Potential impact
- Any suggested mitigation

If Newt or Pangolin credentials may have been exposed, rotate them immediately. Service annotations are configuration authority: anyone permitted to annotate a watched Service can request public exposure through this controller.
